# Ticket Types: Price, Capacity, and Forms Per Option

One price and one capacity isn't always enough. Mixed doubles need Men's and Women's. Clubs want Early Bird and Standard. Social sessions need Member and Guest. That's why we've launched **Ticket Types** - multiple booking options on a single event, each with its own price, capacity, and registration form.

Players choose a ticket type when they book. You manage inventory and forms per type from your Organiser Hub.

<!--more-->

## Why Organisers Love It

Ticket Types give you flexible inventory without splitting one session into multiple events:

- **Different prices** - Early Bird, Standard, or Member vs Guest on the same event
- **Separate capacity** - fill Men's and Women's spots independently, or cap VIP seats while General Admission stays open
- **Forms per type** - attach a different registration form to each option, or leave some types form-free
- **Clear buyer choice** - attendees see the type name, price, and remaining spots before they pay

New events still start with a single **General Admission** type. Add more types whenever you need them.

## What Players Experience

From the player's side, booking stays simple:

1. They open your event page
2. If there's more than one ticket type, they pick the option they want
3. They see that type's price and availability
4. Checkout uses that type - including any form attached to it

If a type is sold out, it's marked clearly so they can choose another option or waitlist where available.

## How to Set It Up (Organiser Hub)

Ticket Types live in your event's **Settings** tab in Organiser Hub:

1. Open your event in the [Organiser Hub](https://www.sportshub.net.au/organiser)
2. Go to **Settings**
3. Under **Ticket Types**, click **Add Type**
4. Set the **name**, **price**, **capacity**, and optional **registration form**
5. Save - buyers can select the new type immediately

You can edit a type anytime. You can delete a type only if no tickets have been sold for it, and every event must keep at least one ticket type.

Forms stay in sync too: the **Forms** tab lets you switch between ticket types to attach forms and review responses for each option.

## Try It Out

Running a session with more than one booking option? [Set up Ticket Types in your event settings](/docs/organisers/events/ticket-types) and let players choose the right spot.
